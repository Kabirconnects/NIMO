# Experiments

Hypotheses, runs, and results. Every experiment follows the same format:

```
# YYYY-MM-DD — Title

## Hypothesis
What we think will happen, and why.

## Setup
What we changed, what we measured, what the baseline was.

## Result
What actually happened. Numbers first.

## Conclusion
What we keep, what we discard, what we try next.
```

## What goes here

- Retrieval algorithm comparisons (vector-only vs hybrid vs graph).
- Synapse weight / activation parameter sweeps.
- Consolidation strategy trials.
- Neuron-type ablations — do `decision` and `preference` need different
  handling?
- Negative results. What *didn't* work is as valuable as what did.
