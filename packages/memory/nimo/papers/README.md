# Papers & sources

Notes on the research that taught Nimo. One file per paper: what it says,
what Nimo takes from it, and where Nimo diverges.

## Reading order

1. **A-MEM** (NeurIPS 2025) — dynamic memory notes, linking, evolution.
   Closest foundation: dynamic notes, automatic links, memory evolution.
   https://arxiv.org/abs/2502.12110
2. **HippoRAG** (NeurIPS 2024) — knowledge graphs + Personalized PageRank,
   multi-hop retrieval. Foundation for synapse traversal and activation.
   https://arxiv.org/abs/2405.14829
3. **AgeMem** (ACL 2026) — memory ops as agent actions (store, retrieve,
   update, discard). Foundation for the agent-facing tool surface.
   https://aclanthology.org/2026.acl-long.981/

## What goes here

- `a-mem.md`, `hipporag.md`, `agemem.md` — one file per paper with the
  comparison-to-Nimo table.
- Notes on spreading activation, memory consolidation, and forgetting
  curves from cognitive science.
- Links and quotes, not copies of full text. Respect the source.
